# 宝石迷宫

单人塔防浏览器试玩版，首页可选择经典模式或快速模式。经典模式放五留一、自由造路，在地穴、森林、冰雪遗迹与深渊大地牢四张地图守住十二波；快速模式适合手机竖屏，金币召唤、同类叠放、三合一升级、配方合成和环廊防守。

鼠标或触屏操作。首页与快速模式保持自然竖屏；经典模式在手机上自动使用横屏布局，关闭自动旋转也能玩。经典模式 Enter 开波、Space 暂停、X 倍速；快速模式 Space 召唤、Enter 开波、Esc 暂停。

试玩：https://le0zh.github.io/gem-maze/

支持安装为 PWA 应用。Android/Chrome 点击页面的“安装应用”；iPhone 在 Safari 中点击“分享 → 添加到主屏幕”，保持“作为 Web App 打开”开启。从主屏幕图标进入可隐藏浏览器地址栏。完整缓存后支持离线游玩；缓存可能被系统回收。

此仓库仅包含 Godot Web 发布包。GitHub Pages 从 main 分支根目录发布。
